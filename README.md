# 캠퍼스 자동 기록

대학생을 위한 자동 기록 프로토타입입니다. 사용자가 직접 입력하지 않아도 위치와 결제 알림에서 데이터가 쌓이는 구조를 보여줍니다.

## 기능

### 1. 공부 장소 집중 패턴
- 위치 좌표(5분 간격)를 받아 등록된 장소 반경 80m 안에서 10분 이상 머문 구간을 방문으로 감지
- 장소별 체류 시간 집계 및 막대그래프 표시
- 현재는 하루치 위치 데이터를 시뮬레이션으로 생성

### 2. 커피 결제 자동 기록
- 결제 알림 문자에서 가게 이름, 금액, 날짜, 시간 추출
- 커피 가게 키워드에 해당하는 결제만 기록 (중복 결제는 무시)
- 누적 잔 수, 총 지출, 평균 단가 표시
- 기록은 브라우저 localStorage에 저장

## 실행 방법

`campus-auto-log.html` 파일을 브라우저에서 열면 됩니다. 별도 설치나 서버가 필요 없습니다.

## 코드 구조

| 함수 | 역할 |
|------|------|
| `genPings()` | 하루치 위치 데이터 시뮬레이션 |
| `detectStays()` | 위치 좌표를 장소별 체류 구간으로 변환 |
| `parseLine()` | 결제 알림 한 줄에서 가게, 금액, 시간 추출 |
| `isCoffee()` | 커피 가게 판별 (`COFFEE` 키워드 목록 사용) |

## 실제 앱으로 확장하기 (안드로이드)

- 위치: Fused Location Provider 또는 Geofencing API로 좌표 수집, `detectStays` 로직 이식
- 결제: `NotificationListenerService`로 카드사 알림 수신 후 `parseLine` 로직 이식
- 카드사마다 알림 문구가 달라 파서에 형식 추가 필요
- iOS는 다른 앱의 알림을 읽을 수 없어 결제 연동이 제한됨
- 위치와 결제 정보는 기기 안에서 처리하고, 권한 사용 목적을 사용자에게 명확히 안내

## 장소 설정

`PLACES` 배열의 이름과 좌표를 수정하면 본인 학교 주변 장소로 바꿀 수 있습니다.

```js
const PLACES=[
 {n:"중앙도서관",la:37.2840,lo:127.0450,study:true},
 ...
];
```
